# Windows Distribution Usage

To launch the Windows version of the web tool:

1. Download the Windows version of the webtool from the
   [Github releases page](https://github.com/Big-Life-Lab/PHES-ODM-Validation-Web/releases)
2. The downloaded file is an installer that needs to be run.
3. After installation you can run it from the desktop shortcut or start menu
   entry.

   A terminal windows should open in the background and a browser window should
   open automatically after a few seconds, but if it doesn't then click on this
   [link](http://127.0.0.1:8050/).
